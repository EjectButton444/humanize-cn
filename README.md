# deai：AI文字特征去除器（仅限中文）

![deai 概念图](docs/deai-concept.jpg)

> *『自己的AI还在以最直白最直接最不绕弯子的方式输出？』*
> *『还在苦恼一键生成的文本完全**不说人话**，完全无法通过？』*
> *『快来试试 **最新，最潮，最强**（存疑）的AI文字特征去除器吧！』*

## 它能做什么

- 去除 AI 输出中的高频词、让你的AI不再以最直白最直接，最不绕弯子的方式告诉你
- 根据语境与使用场景，自动选择更加贴合的语气，拒绝古风小生
- 在情景恰当时增添更多主观看法，让文章更有人味
- 听从您的修改意见，在您提出修改意见后自动记入并写入skill，不断成长

## 使用方法
安装好该skill后，告诉AI类似于以下内容的文本
> 帮我润色一下/改写一下这段
> 输出自然一些/看起来像人一些
> 输入 **/deai** 手动调用

#### tips:
如果是让AI自由生成文本，它会主动申请让您提供一些细节，以更好的增加真实性，此为正常可选流程，没有跳过即可。

## 安装

### 方式一：npx（安装到 DeepSeek Harness）

```bash
npx deai-skill-cn             # 安装到全局（~/.dsh/skills/deai）
npx deai-skill-cn --project   # 安装到当前项目（./.dsh/skills/deai）
```

### 方式二：手动安装（任意支持 Agent Skills 的工具）

把 `SKILL.md` 和 `example.md` 复制到对应工具的技能目录：

| 工具 | 全局目录 | 项目目录 |
|---|---|---|
| DeepSeek Harness | `~/.dsh/skills/deai/` | `<项目>/.dsh/skills/deai/` |
| Claude Code | `~/.claude/skills/deai/` | `<项目>/.claude/skills/deai/` |
| OpenAI Agent / Codex | `~/.agents/skills/deai/` | `<项目>/.agents/skills/deai/` |


## 目录结构

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 技能主体：触发条件、规则与场景表、三套审查标准、质量评价、纠错学习 |
| `example.md` | 问题诊断例库：典型问题句 + 诊断 + 改进 |
| `install.js` | npx 安装脚本（无依赖，把上述两个文件复制进 DSH 技能目录） |
